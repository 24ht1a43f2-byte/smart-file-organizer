# Smart File Organizer

## About the Project

Smart File Organizer is a Python project that automatically organizes files into separate folders based on their file types.

## Features

* Organizes PDF files
* Separates images, documents, videos, and audio files
* Organizes spreadsheets
* Places unknown file types into an Others folder
* Avoids overwriting files with duplicate names

## Technologies Used

* Python
* pathlib
* shutil

## How to Run

1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python organizer.py
```

5. Enter the folder path you want to organize.

## Safety Note

Test the program using a sample folder before organizing important files.
